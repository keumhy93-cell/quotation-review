# 작업환경측정 견적서·결과서 검토

현대건설(품셈) · 계룡건설 · 한화건설(단가제) 측정 견적서와 결과서를 올리면 오류를 찾아 주는 도구입니다.
파일은 **브라우저 안에서만** 읽습니다(서버 업로드 없음).

```bash
npm install
npm run serve      # http://localhost:8080  (스크립트가 /web/index.html 로 이동)
npm test
```

## 무엇을 검토하나

### 현대건설 견적서 (정기/수시 × 자동/수동, 파일 구조로 유형 자동 판별)
| 구분 | 내용 |
|---|---|
| 갑지 | 견적금액 계수 정기 ×0.8 / 수시 ×0.55, 직접인건비·직접경비가 세부내역서와 수식으로 연결됐는지, 금액 재계산 |
| 인건비 | 정기/수시 노임단가(특·고·중·초급), 계획서 측정인원수·물리인자 방법별 건수·분석방법별 건수와 일치 |
| 계획서 ↔ 재료비 | 다성분 병합(첫 행에만 건수) 규칙으로 시료 그룹을 만들어 유해인자별 건수 대조, 분석방법 일치 |
| 공시료 | 재료비내역서에 공시료가 있는지, 측정한 모든 화학인자에 공시료가 있는지, 측정 안 한 인자의 공시료가 없는지 |
| 재료비 금액 | 측정+분석=합계, 0원(단가 누락) 행, 합계 ↔ 직접경비 연결 |
| 명칭 | 방법명이 인건비 SUMIF 조건과 공백까지 같은지(오타면 인건비에서 누락), 유해인자가 마스터 목록에 있는지, 단성분/다성분 모순 |
| 인원 ↔ 건수 | 1~10인 2건, 이후 5인마다 +1건, 최대 20건 (근로자가 더 적으면 근로자 수만큼) |
| 사업장 제출용 엑셀 | 실시현황(수수료·출장여비·감가상각비·재료비·구분·현장명)과 계획서·재료비가 견적서와 같은지 |

### 계룡·한화(단가제) 수수료 산출근거 엑셀 (현장 블록 여러 개)
기본관리비(근로자수 → 규모 구간 → 단가), 분석방법별 단가표 일치, 샘플링 수 = 인원 기준 건수, 금액 = 건수×단가,
합계 체인, 공종별 근로자수 합 ≤ 총 근로자수, 실시현황(현장명·구분·최종수수료) 대조, 상호 표기 일관성.

### 결과서 (PDF 또는 엑셀) — 별지 82호·83호 + 종합의견
갑지 전회(건설업은 "2회 연속 미만/초과" 체크 불가), 인원수 ↔ 측정건수, 부서별 근로자수 합 ↔ 사업장 근로자수,
측정계획 ↔ 결과표 시료 수(누락·과다 측정), 측정결과 요약 ↔ 측정계획, 분포실태 유해요인 ↔ 측정계획,
사용실태 비고의 유해인자 ↔ 측정계획, 임시·단시간 허용소비량(분포실태 기재·사용빈도), 노출기준 초과 목록.
여러 결과서를 올리면 결과서 간(같은 현장 중복, 상호 표기 상이)도 비교합니다.

### 결과서 ↔ 견적서
유해인자 **조합**(한 시료로 묶인 인자 세트)과 건수가 모두 같은지. 단가제는 결과서의 현장명으로 견적 블록을 찾아
공종별 인원·유해인자별 건수까지 대조합니다.

## 구조
```
src/core/   hyundai.js(현대 견적) unitprice.js(계룡·한화) result-pdf.js(결과서 PDF) rules-result.js(결과서 엑셀·조합 비교)
            util.js config.js read.js pdf-lines.js index.js(runReview)
web/        index.html app.js style.css pdf-text.js vendor/(SheetJS, pdf.js)
test/       합성 데이터 테스트 (실제 고객 파일은 저장소에 넣지 않았습니다)
```
기준값(노임단가·계수·유해인자 별칭·분석방법 별칭)은 화면의 **설정** 탭 JSON 에서 바꿀 수 있습니다.

## 확인된 한계
- 현대 **수동** 견적서는 빈 양식으로만 확인했습니다(직접입력 블록 H~N 열 규칙은 추정). 작성된 수동 견적서로 한 번 더 검증이 필요합니다.
- 결과서 PDF 의 **사용실태 표**와 **임시·단시간 허용소비량** 표시 양식은 해당 내용이 있는 샘플이 없어 키워드 기반입니다.
- 현대건설 결과서는 PDF 샘플이 없어 계룡·한화 결과서 양식으로 만들었습니다.
- 스캔(이미지) PDF 는 텍스트가 없어 읽을 수 없습니다.
