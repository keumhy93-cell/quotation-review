# 작업환경측정 견적서·결과서 검토 · 분기 취합

현대건설(품셈) · 계룡건설 · 한화건설(단가제)의 측정 견적서·결과서를 검토하고,
기관(센터)별로 모은 자료를 **누락 알림 → 오류 요약 → 수정본 비교 → 이력 → 최종 확정 → 건설사별 폴더 ZIP** 으로 취합합니다.

## 사용 방법 3가지
| 방법 | 대상 | 방법 |
|---|---|---|
| **파일 하나** | 혼자·소수, 설치 불가 | `dist/review.html` 만 받아 더블클릭. 이력은 그 PC 브라우저에 저장 |
| **공유 서버** | 여러 사람이 같은 이력 사용 | `node server/server.mjs --static dist --data ./data` 실행 후 주소 공유 (아래) |
| **관리 화면에 임베드** | 기존 사내 화면 | `mountReview(el, opts)` 위젯 (아래) |

```bash
npm install
npm test            # 단위 테스트 (가상 데이터)
npm run build       # dist/ 생성 (review.html · index.html · quotation-review.js · vendor/)
npm run serve:team  # 공유 서버 (http://localhost:8080)
```

## 화면 구성 · 저장 위치

왼쪽 세로 메뉴(분기 작업 · 단가 등록 · 빠른 검토 3개 · 기준 관리 · 저장 위치)에서 화면을 고르고, 화면 안에서는 위쪽 탭으로 기능을 나눕니다(분기 작업: 파일 올리기 / 오류 요약 / 기관별 수정본 / 취합·다운로드 / 작업 이력).

**어느 PC에서든 같은 이력·단가표를 보려면 「저장 위치」에서 고르세요.**
- **공유 폴더**(서버 불필요, Edge·Chrome): 모든 PC에서 접근되는 폴더(회사 공유 드라이브, OneDrive·SharePoint 동기화 폴더)를 고르면 이력·단가표·업로드 파일이 그 폴더(`projects/`, `blobs/`)에 저장됩니다. 각 PC가 같은 폴더를 한 번씩 연결하면 됩니다. 브라우저를 다시 열면 「허용」을 한 번 눌러야 할 수 있습니다. 같은 작업을 동시에 저장하면 잠금 파일로 순서를 맞추고, 충돌 시 자동으로 최신본을 합쳐 다시 저장합니다(동기화 폴더는 반영이 늦을 수 있어 같은 기관을 동시에 수정하지 않는 것이 안전합니다).
- **공유 서버**: `npm run serve:team` 주소(+토큰)를 입력. 파일(review.html)로 열 때는 서버를 `--cors` 로 실행합니다.
- **이 PC의 브라우저**: 기본값. 다른 PC에서는 보이지 않습니다.

저장 위치를 바꿀 때 「기존 작업·단가표를 새 위치로 복사」를 켜 두면 지금까지의 자료가 옮겨집니다(같은 작업이 이미 있으면 건너뜀).

## 분기 작업 화면
1. **작업 열기** — 건설사 + 기간(예: `2026-2분기`) + 검토 방식(분기 전체 흐름 / 수시 견적↔계획서)
2. **기관 업로드** — 센터가 보낸 파일을 한꺼번에 올리면 종류를 자동 분류 (견적 엑셀·견적 PDF·사업장 제출용·산출근거·실시현황·결과서)
3. **누락 알림** — 견적 있는데 결과서 없음, 결과서 있는데 견적 없음, 실시현황과 현장 불일치 등을 팝업으로 알리고
   `사유 입력 후 진행 / 보류(수정본 요청) / 무시` 중 응답을 받아 이력에 남김
4. **오류 요약** — 기관 → 현장 → 분류별로 어떤 오류인지 요약 (엑셀로 저장 가능)
5. **수정본** — 같은 기관이 다시 올리면 r2, r3…로 쌓이고, 같은 현장 파일은 교체. 이전 리비전과 **해결 / 남음 / 새로 생김** 비교
6. **최종 확정** — 오류·미응답 누락이 없어야 확정, 있으면 사유를 적어 예외 확정 (사유는 이력·요약에 남음)
7. **취합·다운로드**
   - **실시현황 취합**: 올린 기관 순서 → 파일 안 행 순서대로 **연번을 1부터 다시 부여**(↑↓로 순서 변경). 건설사별 양식(현대 18열/계룡 13열/한화 12열)을 첫 파일 양식 그대로 복원(제목·헤더·병합·열너비·날짜/금액 서식), 중복 현장(같은 현장·구분·본측정일)은 알림
   - **사용실태 취합**: 결과서의 「공정별 화학물질 사용 상태」 표를 모든 기관에서 모아 실시현황 연번 순서로 정리
   - **폴더별 ZIP**: `기간/건설사/` 안에 `실시현황_…xlsx`, `사용실태_…xlsx`, `결과서/001_현장명.pdf`, `견적서/기관/…`, `검토요약_…xlsx`(기관별 요약·상세·이력·누락 응답). **반기 병합**은 이전 분기를 체크하면 분기 순서 → 업로드 순서로 연번을 이어 붙임
8. **이력** — 업로드·수정본·누락 응답·확정·다운로드가 작업자 이름과 함께 기록됨. 올린 원본 파일도 모두 보관

### 다성분(한 시료로 묶기) 규칙
같은 분석방법(예: ICP)이라도 아무 인자나 묶을 수 있는 것은 아닙니다. 기본 규칙: **수산화나트륨은 수산화칼륨과만** 한 시료로 묶을 수 있고, **주석(유기화합물)은 단성분**이라 어떤 인자와도 묶이면 안 됩니다. 계획서·재료비내역서에서 이를 어기면 `다성분` 오류로 알리고, 건수 합이 어긋날 때 '병합 누락' 원인 후보에서도 이 규칙에 맞는 인자끼리만 지목합니다. 규칙은 설정의 `bundleRules`(`single`: 단성분 목록, `onlyWith`: 서로끼리만 묶이는 인자 목록)로 추가·수정합니다.

## 단가 등록 (매년 노임단가·재료비단가·기본관리비·기본단가)
화면 상단 **단가 등록** 탭에서 연도를 정해 올립니다. 검토할 때는 **작업 기간의 연도**(예: `2026-2분기` → 2026년) 단가표가 자동으로 쓰이고,
「빠른 검토」에서는 `단가 기준 연도`를 고릅니다. 해당 연도가 없으면 기준 관리의 기본값으로 검토하고 그 사실을 검토 결과에 안내합니다.
| 건설사 | 올리는 것 | 어디서 | 검토에 쓰이는 곳 |
|---|---|---|---|
| 현대 | 노임단가(정기·수시 × 특·고·중·초급), 견적금액 계수(×0.8/×0.55), 재료비단가표(유해인자별 측정·분석·계·수정재료비·시약), 출장여비율·감가상각률 | **견적 엑셀(.xlsm)** — 정기·수시 파일을 같이 선택하면 둘 다 추출 | 노임단가·계수 일치, 견적 파일의 재료비단가표(별4.재집)가 등록 단가와 같은지(쓴 인자는 오류·안 쓴 인자는 요약 주의), 직접경비 요율 |
| 계룡·한화 | 기본관리비(규모별), 기본단가(분석수수료 규격별) | 견적 엑셀의 **‘단가’ 시트** | 단가 시트가 계약과 같은지, 행 단가·기본관리비가 계약과 같은지 |
- **양식 엑셀**로도 올릴 수 있습니다: `○○○○년 양식 내려받기`(현재 등록값 포함) → 값 수정 → `양식 엑셀 올리기`. 비워 둔 시트는 기존 값을 건드리지 않습니다.
- 올리면 **바뀌는 값만 미리 보여 주고** 확인 후 저장합니다. 같은 값이면 저장하지 않으며, 등록·삭제는 작업자 이름과 함께 이력에 남습니다.
- 공유 서버를 쓰면 단가표도 모두가 같이 씁니다(저장소의 예약 문서 `__pricebook__`). 이 브라우저 저장 모드에서는 이 브라우저에만 있습니다.

## 검토 항목
### 현대건설
- **견적서(엑셀·PDF) 인건비 건수·세부건수 ↔ 측정계획 엑셀**: 인건비 시트의 방법별 세부건수(소음 4.1.1, 분석 5.x), 전체 시료 수, 측정 대상 인원을 측정계획·재료비내역서(공시료 포함)와 대조. PDF 견적서는 pdf.js/pdftotext 어느 쪽 텍스트든 읽음
- **견적서 재료비 세부산출표 ↔ 결과서 대상유해인자**: 재료비 누락·과다, 유해인자 조합·건수
- **결과서 측정계획 ↔ 사용실태 비고**: 사용실태에 있는데 측정계획에 없으면 누락 — 단, 분포실태에 사유가 있거나, 사용실태에 임시·단시간 허용소비량 이하 표시와 **사용 주기**가 있으면 통과. 아니면 오류
- 정기/수시 계수(×0.8/×0.55)·노임단가, 갑지 수식 연결, 공시료, 방법명(SUMIF) 일치, 다성분 기준, 수동 견적의 직접입력↔자동해석 블록 대조
- **수시 검토**는 견적↔측정계획까지만, **분기 검토**는 결과서까지 전체 흐름 (작업 열 때 선택)
### 계룡·한화(단가제)
- 기관 분기 결과서의 분포실태·사용실태 ↔ 대상유해인자 (현대와 동일 규칙)
- 세부견적(공종×유해인자)과 결과서의 유해인자 종류·측정건수 일치
- **계약 조건 단가**: 기본관리비(근로자수 → 규모 구간)·분석수수료 단가, 건수 = 인원 기준, 합계 체인. 「기준 관리」에서 **계약 단가표를 등록**하면 견적 파일의 단가 시트와 행 단가를 계약과 비교
### 결과서(PDF·엑셀) 공통
건설업 전회(「2회 연속 미만/초과」 체크 불가), 인원수↔측정건수(1~10인 2건, 이후 5인마다 +1, 최대 20건 / 근로자가 더 적으면 근로자 수), 부서별 근로자수 합, 측정계획↔결과표 시료, 별표 요약, 분포실태 유해요인, 임시·단시간 허용소비량 사용빈도, 노출기준 초과, 결과서 간(같은 현장 중복·상호 표기).

## 공유 서버
```bash
node server/server.mjs --port 8080 --static dist --data ./data [--token 비밀값] [--cors]
# 또는 npm run serve:team
```
- 의존성 없는 Node(18+) 서버. `data/projects/*.json`(이력), `data/blobs/<sha256>`(올린 파일)에 저장 — **data 폴더만 백업하면 됨**
- 같은 화면 주소로 접속하면 자동으로 서버 저장소를 사용(`공유 서버에 저장` 표시). 서버가 없으면 이 브라우저(IndexedDB)에 저장
- 여러 사람이 동시에 올려도 충돌하지 않도록 프로젝트별 버전(rev) 검사 + 자동 재시도, 같은 파일은 한 번만 저장(해시), 업로드 해시 검증
- `--token` 을 주면 API 접근에 공유 토큰 필요(화면 처음 접속 시 입력). **사용자별 로그인은 없으므로 사내망에서만 쓰세요**
- 사용자 이름은 화면의 「내 이름」에 적은 값이 이력에 기록됨(본인 확인 기능은 아님)

## 관리 화면에 임베드 (위젯)
```html
<div id="review-box"></div>
<script type="module">
  import { mountReview } from './dist/quotation-review.js';
  mountReview(document.getElementById('review-box'), {
    view: 'work',                       // 'work'(분기 작업) | 'hyundai' | 'gyeryong' | 'hanwha'(빠른 검토)
    store: 'auto',                      // 'auto' | 'server' | 'idb' | 'memory' | 직접 만든 저장소
    serverUrl: '', token: '', user: '', // 공유 서버 주소·토큰·작업자 이름
    config: await (await fetch('/api/review-config')).json(),   // (선택) 기준값을 서버에서 관리
    onConfigChange: (cfg) => fetch('/api/review-config', { method: 'PUT', body: JSON.stringify(cfg) }),
    onResult: (r) => console.log(r),    // 빠른 검토 결과
  });
</script>
```
`config`, `storageKey`, `assetBase`, `showConfig`, `companies` 옵션과 반환값(`getConfig/setConfig/getWorkspace/destroy`)은 소스 상단 주석 참고.

## 기준 관리
정기/수시 견적금액 계수·노임단가, 업종, 유해인자·분석방법 별칭, **계약 단가표(계룡·한화)** — JSON 내보내기/가져오기 지원.
수시수동은 정기수동과 규칙이 같고 계수·노임단가만 다릅니다.

## 알아둘 한계
- 취합 실시현황은 값·병합·열너비·날짜/금액 서식을 복원하지만 **셀 색·테두리·글꼴은 복원하지 못합니다**(엑셀 라이브러리 한계).
- 사용실태 취합은 결과서 PDF 표에서 추출합니다. 칸 분리가 안 되는 행은 「원문」 열에 그대로 담깁니다. 별도 사용실태 엑셀 양식은 샘플이 없어 지원하지 않습니다.
- 「임시·단시간 허용소비량 이하」 체크 표시는 해당 양식 샘플이 없어 문구(키워드)로 찾습니다.
- 현대건설 결과서 PDF 샘플이 없어 계룡·한화 결과서 양식으로 만들었습니다. 현대 수시수동 작성본도 없습니다.
- 스캔(이미지) PDF 는 읽을 수 없습니다.
